# 2026-10-29

## 修复网卡误报"未连接"

- 现象：定位到「知行楼7-502(内)」后提示"配置网卡均未连接"，但以太网 7（60-7D-09-0B-34-C4，Lenovo USB Ethernet）实际在位且 Up
- 根因（两个叠加）：
  1. `Get-NetAdapter` 管道经 `ConvertTo-Json` 后 `MediaConnectState` 序列化为数字 `1`/`2`，而 `is_connected` 比较字符串 `'connected'` → 永远 False
  2. 该网卡 IPv4 仅有 APIPA（169.254.x.x，PrefixOrigin=WellKnown），被查询脚本过滤 → ip 为空，"ip+gateway"兜底也失败
- 修复（app/core/nic_info.py）：PS 端显式映射 media 为 Connected/Disconnected；Python `_normalize` 增加数字 media 的防御性映射（_MEDIA_MAP）
- 验证：py_compile 通过；实测 get_adapters 后以太网 7 判定 connected=True
- 附带效果：媒体已连接但仅有 APIPA 的网卡不再被跳过检查，会正常进入"配置不符→提示应用配置"流程
